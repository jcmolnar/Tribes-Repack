Warhammer 40,000: A Tribes Total Conversion
-=-=-=-=-=-==-=-=-=-=-=-=-=-=-=-=-=-=-=-=-=
May 27th, 2000 (1.3.9 release)

CHANGES
--=-=-=-
-Removed Plasma Cannon from Storm Daemon
-Lowered total flight for the Storm Daemon
-Added more weapon choices to Dire Avenger, and Guardian
-Added a bit more punch to the Swooping Hawk and it's Las Blaster
-Reduced sniping weapon firing speed slightly(due to leg and headshots being a common practice now)
-Added Hand Flamer for light units
-Altered the way Flamer weapons work
-Terminator now much more resistant to sniping damage
-Storm Daemon easier to snipe kill(due to its bug of ALWAYS being shot in the leg regardless of hit location)
-Power Sword is now a lethal instrument of death.
-Added mines which are different for each unit type.
-Changed around some beacons.
-Added "trap" fields, which are part of the Tech/Bonesinger mine, and the Warp Spider beacon
-Changed bolter firing graphic(all types of bolter) to reduce lag.
-Fixed range on all bolters. No more sniping with em. 
-Reorganised the weapon files, to make loading a tad faster to reduce overhead.
-Added greater shields to turrets and other defenses
-Removed the Sattelites Orbital Cannon, replaced it with a Sattelite Defense Unit.
-Wraithguard now has only 1 beacon shield instead of 3.
-Various other alterations were made, though the most important are mentioned above.

Installation
-=-=-=-=-=-=

Install all files into your Tribes/War40k directory.  The .lnk file will run a dedicated server.  (If you installed the game to another directory you will need to modify the .lnk file with the new directory.)  To run a non dedicated server do the following.

Create a Shortcut of Tribes.exe

set its Properties to run:

tribes.exe -mod War40k

then run, Host Game, and yer set.


NOTE: Some people have reported problems when hosting. In Dedicated, some report inability to spawn. In Non-Dedicated the inv stations sometimes seem to be blank.

We dont yet know for sure about the non spawning in dedicated. If this occurs, be sure to contact us and we can try to track down a possible solution to the error.
