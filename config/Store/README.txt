Asset Store preview thumbnails.

Drop <packId>.png here (e.g. tac.png, rmrpg.png) and set "preview": "Store/<packId>.png"
on the pack's entry in the store catalog (C:\Dynamix\Tribes-Asset-Store\catalog.json).
The store page shows the image in the pack's detail panel; without one it shows the
category glyph. Suggested size ~400x150, PNG. This folder SHIPS with the game (see
tools\repack-whitelist.txt) so a preview is present before the pack it advertises.
