40K Scoring System        
-=-=-=-=-=-=-=-=-=-
This wonderful system works off the max damage the object/armor can take.  The only current imbalance is the Storm Demon and we hope to have that corrected for the next release. (Again...)
Tkers will be suprised when the armor they kill gives a set value instead of the difference between armors.
Armor values range from 1 - 12.  The highest object value I've seen so far is 5.  (I take it back.  I've now seen an object give 10 points for a kill and 15 for repair, but I'm not telling which one...)
Only mission items give points for destroying and repairing. (i.e. Generators, inventory stations, ammo stations, etc.) you get more points for repairing items than for destroying them because it takes longer to repair.  On a side note, there are some objects that will give you points for repair that don't give points for killing.  Again, play around a little.  You'll find them.
 If you see other imbalances, let us know.
